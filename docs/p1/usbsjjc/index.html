p1-usb刷机教程

P1-USB刷机教程​

danger

请确保盒子刷过myt-p1-v0.4.4.202504281000以及之后版本的固件，否则不支持使用usb刷机

warning

在使用USB刷机时，请确保P1盒子内没有硬盘

否则会直接从硬盘启动

下载并打开usb刷机工具

选择usb刷机镜像

点击写入来将usb烧录为启动盘

将usb插入P1的usb口后，再接通电源自动开机即可。
