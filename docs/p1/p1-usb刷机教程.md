## P1-USB刷机教程

:::warning

在使用USB刷机时，请确保P1盒子内没有硬盘

否则会直接从硬盘启动

:::

下载并打开usb刷机工具

![image-20250428180941202](/img/p1/usb1.png)

选择usb刷机镜像

![image-20250428180959280](/img/p1/usb2.png)

点击写入来将usb烧录为启动盘

![image-20250428181624454](/img/p1/usb3.png)

将usb插入P1的usb口后，再接通电源自动开机即可。
