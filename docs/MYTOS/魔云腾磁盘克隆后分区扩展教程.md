# 魔云腾磁盘克隆后分区扩展教程

## 6. 开始扩展分区

### 6.1 删除原分区（一定要记下开头，不然加不回来）

命令(输入d回车)：  
```
Command (m for help): d
Selected partition 1
Partition 1 has been deleted.
```

显示Partition x has been deleted.
表示才能成功，注意P1是Partition 3 has been deleted.
**不同设备不一样！！！，都是最后一个分区**

![删除原分区](/img/MYTOS/137556117635062.png =336x)

### 6.2 添加修改后的分区

命令1（输入n回车）:  
```
Command (m for help): n
```

命令2（直接回车）
```
Partition number (1-128, default 1):
```

命令3（输入2048的起始位置，P1不一样，需要自己观察步骤5中自己设备的最后一个分区信息）
```
First sector (2048-500118158, default 2048): 2048
```

命令4（末尾位置，直接回车）
```
Last sector, +/-sectors or +/-size{K,M,G,T,P} (2048-2000409230, default 2000409230):

Created a new partition 1 of type 'Linux filesystem' and of size 953.9 GiB.
Partition #1 contains a ext4 signature.

```

命令5（输入N回车！！！不要移除分区信息）
```
Do you want to remove the signature? [Y]es/[N]o: N
```

#### 没有命令5这一步，表示操作错误，没有找到原来的分区，请直接输入q回车重来

### 6.3 检查结果
命令6：查看更改后的分区信息
```

Disk model: NVME 4.0 1TB

/dev/nvme0n1p1  2048 2000408575 2000406528 953.9G Linux filesystem

Command (m for help):
```

#### (1) 创建的分区存在表示成功，直接输入w回车保存

命令（输入w回车）
```
Command (m for help): w
The partition table has been altered.
Syncing disks.

/home/user #
```

#### (2) 如果不存在或者起始位置不对，不要搞别的操作，直接q回车，不保存更改，退出重来

命令（输入q回车）
```
Command (m for help): q

/home/user #
```

## 7. 调整内容大小

命令（resize2fs /dev/nvme0n1p1）：
```
/home/user # resize2fs /dev/nvme0n1p1
resize2fs 1.47.1 (20-May-2024)
The filesystem on /dev/nvme0n1p1 is now 250050816 (4k) blocks long.

/home/user #
```
