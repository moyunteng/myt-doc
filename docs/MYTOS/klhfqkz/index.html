魔云腾磁盘克隆后分区扩展教程

注意！操作前请注意数据备份，以免操作不当导致数据丢失（保留原硬盘等），更换硬盘时请戴好防静电手环或手套，注意接地良好，以免身上静电打坏设备。​

1. 把完成数据克隆后的硬盘插回原始设备​

2. 设备开机，通过客户端或者屏幕等查询设备IP​

这里以10.10.0.187为例

3. SSH连接设备​

3.1 方式1：使用putty连接​

3.2 方式2：使用windows自带ssh​

![windows终端](/img/MYTOS/383744534403678.png =876x)

默认登录用户：user

默认登录密码：myt

4. 进入分区工具​

命令：

fdisk /dev/nvme0n1

![进入分区工具](/img/MYTOS/96234870787274.png =1186x)

5. 获取现在分区状态​

命令(输入p回车)：

Command (m for help): p

Disk /dev/nvme0n1: 953.87 GiB, 1024209543168 bytes, 2000409264 sectors
Disk model: NVME 4.0 1TB
Units: sectors of 1 * 512 = 512 bytes
Sector size (logical/physical): 512 bytes / 512 bytes
I/O size (minimum/optimal): 512 bytes / 512 bytes
Disklabel type: gpt
Disk identifier: B4106DD7-B01E-0C40-AF3B-7E9826569FE0

Device         Start       End   Sectors   Size Type
/dev/nvme0n1p1  2048 500117503 500115456 238.5G Linux filesystem

![查看分区](/img/MYTOS/547471171938497.png =620x)

记录分区起始2048​

6. 开始扩展分区​

6.1 删除原分区（一定要记下开头，不然加不回来）​

命令(输入d回车)：

Command (m for help): d
Selected partition 1
Partition 1 has been deleted.

显示Partition x has been deleted. 表示才能成功，注意P1是Partition 3 has been deleted. 不同设备不一样！！！，都是最后一个分区

![删除原分区](/img/MYTOS/137556117635062.png =336x)

6.2 添加修改后的分区​

命令1（输入n回车）:

Command (m for help): n

命令2（直接回车）

Partition number (1-128, default 1):

命令3（输入2048的起始位置，P1不一样，需要自己观察步骤5中自己设备的最后一个分区信息）

First sector (2048-500118158, default 2048): 2048

命令4（末尾位置，直接回车）

Last sector, +/-sectors or +/-size{K,M,G,T,P} (2048-2000409230, default 2000409230):

Created a new partition 1 of type 'Linux filesystem' and of size 953.9 GiB.
Partition #1 contains a ext4 signature.

命令5（输入N回车！！！不要移除分区信息）

Do you want to remove the signature? [Y]es/[N]o: N

没有命令5这一步，表示操作错误，没有找到原来的分区，请直接输入q回车重来​

6.3 检查结果​

命令6：查看更改后的分区信息

Command (m for help): p

Disk /dev/nvme0n1: 953.87 GiB, 1024209543168 bytes, 2000409264 sectors
Disk model: NVME 4.0 1TB
Units: sectors of 1 * 512 = 512 bytes
Sector size (logical/physical): 512 bytes / 512 bytes
I/O size (minimum/optimal): 512 bytes / 512 bytes
Disklabel type: gpt
Disk identifier: B4106DD7-B01E-0C40-AF3B-7E9826569FE0

Device         Start       End   Sectors   Size Type
/dev/nvme0n1p1  2048 2000408575 2000406528 953.9G Linux filesystem

Command (m for help):

(1) 创建的分区存在表示成功，直接输入w回车保存​

命令（输入w回车）

Command (m for help): w
The partition table has been altered.
Syncing disks.

/home/user #

(2) 如果不存在或者起始位置不对，不要搞别的操作，直接q回车，不保存更改，退出重来​

命令（输入q回车）

Command (m for help): q

/home/user #

7. 调整内容大小​

命令（resize2fs /dev/nvme0n1p1）：

/home/user # resize2fs /dev/nvme0n1p1
resize2fs 1.47.1 (20-May-2024)
The filesystem on /dev/nvme0n1p1 is now 250050816 (4k) blocks long.

/home/user #
